Entry for make.fun's **The Absurd Clause Contest**
(`u-donrulezz-the-absurd-clause-contest-035cc0f1`, $2 pot split over the top 10).

`main.ts` (Node 22, no dependencies) writes one original absurd clause, buried
deep in terms-of-service boilerplate, to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or
`/output/entry.txt` when the variable is unset). The clause is a fixed string
in the source: deterministic, no network, no randomness, no trailing newline.

Run it:

```sh
node main.ts
```
